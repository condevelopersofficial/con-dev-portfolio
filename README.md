# CON Developers Portfolio

This repository contains the Next.js version of the CON Developers portfolio.

## Run locally

```powershell
cd con-dev-portfolio-next
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

## Production build

```powershell
cd con-dev-portfolio-next
npm run build
```

The site is configured as a static export. Netlify publishes the generated `out` folder.

Node.js 18.17 or later is required.
